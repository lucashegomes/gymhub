# Buttons

Variants: `primary`, `secondary`, `outline`, `ghost`, `destructive`.

States:
- Default
- Hover
- Focus (`focus-visible:ring-2`)
- Disabled (`opacity-50`, no pointer events)
- Loading (show spinner, disable click)

Guideline:
- Primary actions must use `primary`.
- Destructive actions must use `destructive` and explicit confirmation.
